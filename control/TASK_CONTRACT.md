# TASK CONTRACT

Every delegated job uses this shape:

INPUT
- goal
- current state
- constraints
- relevant files
- acceptance criteria
- allowed tools
- forbidden changes

OUTPUT
- changed files
- tests run
- test results
- deployment result
- live verification result
- known risks
- decision record

FAILURE
- stop
- report exact failing layer
- do not reset unrelated working code
- propose smallest repair
