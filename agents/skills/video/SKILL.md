Pipeline:
idea → research → script → shot list → assets → voice → captions → Remotion composition → FFmpeg render → QA → export.

Free-first stack:
- Remotion for programmatic composition
- FFmpeg for encoding/editing
- Piper or another local TTS when appropriate
- Pexels/Pixabay or user assets for licensed stock
- Whisper/WhisperX for transcription/captions when available

Never assume an AI video API is free. Track provider, quota and license.
