---
name: coding
description: Build and modify web apps safely with GitHub, isolated modules, tests and deployment verification.
---
1. Inspect repository state before editing.
2. Identify protected modules and current entry points.
3. Prefer small isolated changes.
4. Never overwrite working subsystems to add unrelated features.
5. Run syntax/tests/build before deployment.
6. After deployment verify the exact deployed commit and workflow result.
7. Record what changed and why in control/DECISIONS.md.
