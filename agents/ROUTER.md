# HEAD ROUTER

User request → classify → load skills → delegate → QA → record.

Examples:
- "سایت بساز" → CODER + DESIGN + QA
- "اینستاگرام را بررسی کن" → SOCIAL + MARKETING + QA
- "ریلز زمین بساز" → VIDEO + SOCIAL
- "یوتیوب را راه بینداز" → YOUTUBE + VIDEO + MARKETING
- "اپ را تغییر بده" → CODER + ARCHITECT + QA
- "CRM را تغییر بده" → CRM + CODER + QA
- "محاسبه مشارکت را اصلاح کن" → CONSTRUCTION + QA
- "کل سیستم را ارتقا بده" → HEAD splits into domain jobs, then integration QA

No domain agent may silently change another domain.
